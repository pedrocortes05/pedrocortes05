# Hi, I'm Pedro

Backend and infrastructure engineer in México. I build Rails apps and then run the
machines they live on.

Day job: IT/backend at a freight and logistics company, where I work on Rails 8
services, third-party integrations (accounting, freight management, and SAT/CFDI 4.0
electronic invoicing), and the AWS/Docker infrastructure underneath them.

Off the clock: a small self-hosted fleet — NixOS and Arch boxes, a Raspberry Pi, Docker
Compose, Cloudflare Tunnel, and cross-built ARM images pushed to GHCR — hosting Rails
apps, Immich, Nextcloud, and n8n automations.
